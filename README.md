# Host Computer Releases

这里提供 Host Computer 脑电采集与信号分析上位机的公开 Windows x64 发布包。

请在 [Releases](https://github.com/Yuwenhe1234/HostComputer-Releases/releases) 页面下载最新版本。解压后运行 `HostComputer.Desktop.exe`，无需另行安装 .NET 运行时。

v0.19.0 支持八通道实时采集与历史回放中的显示滤波、PSD、FFT，以及 Delta、Theta、Alpha、Beta、Gamma 五频段结果。原始 `.eegraw` 和 CSV 数据保持未滤波。

本软件用于研发采集和信号分析，研究指标不替代临床监护设备或专业判断。
